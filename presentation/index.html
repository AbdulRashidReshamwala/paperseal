WHAT WE DON’T CLAIM

We say it out loud.

After it opens

A centre could still leak the paper once it decrypts it. So the window stays as short as possible.

The clock

We rely on the public time network. If it fails, opening is delayed, not exposed.

The code

Proof shows which code runs, not that it has no bugs. That is why it is open to review.
